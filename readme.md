# 🏫 Hope English Language Center – Website

A **full-stack web application** being developed for *Hope English Language Center*.
The platform is designed to showcase the center, support students in their English learning journey, and provide interactive features for vocabulary, grammar, and more.

## 📚 Planned Features

* **Homepage** – Modern, responsive landing page with information about the center.
* **Vocabulary Page** – Learn and practice words with examples and meanings.
* **Grammar Section** – Step-by-step grammar lessons and exercises.
* **Blog Section** – Articles and resources to improve reading and comprehension.
* **Quizzes & Tests** – Online practice tests to evaluate learning.
* **User Authentication** – Secure student and admin login.
* **Announcements & Notices** – Latest updates from the coaching center.

## 🛠️ Tech Stack (Planned)

* **Frontend:** html / javascript
* **Backend:**  PHP
* **Database:** MySQL
* **Styling:**  CSS 
* **Version Control:** Git & GitHub

## 🚀 Project Status

🔹 Currently under **active development**.
🔹 First phase: core pages (Home, Vocabulary, Grammar, Blog).
🔹 Next phases: authentication, tests, and progress tracking.


## 🎯 Purpose

The goal of this project is to create a **professional, user-friendly website** for *Hope English Language Center* that helps students learn effectively while also serving as an information hub for the institute.
