SEO meta tags (title, description, og:image placeholder).

Phase 5 — Backend (PHP + MySQL) — wire up functionality

Start connecting forms and admin actions to PHP endpoints. Suggested order:

Setup backend/config.php (use PDO, prepared statements).

Implement admin auth: login (sessions), logout, restrict admin pages (session check). Hash passwords (bcrypt).

Implement CRUD for Blog (add/edit/delete) — a good first module to test file uploads and DB flow.

Implement CRUD for Vocabulary & Grammar.

Implement Events & Event registration storage (event_registrations). Replace registration Google Form if/when you decide.

Implement Gallery image upload (with upload folder & validation).

Implement Testimonials submission + admin approval flow.

(Optional later) Implement native Tests engine: questions table, test run, scoring, history.

Security checklist:

Use prepared statements (no raw SQL concat).

Validate & sanitize all inputs server-side.

Protect file uploads (type checks, size limit, random filenames).

Implement CSRF tokens for admin forms.

Rate-limit or captcha on public forms if spam appears.

Done when: Admin can login and create blog posts/vocab/grammar/events and those appear on public pages pulling from DB.

Phase 6 — QA, optimization & deployment

Cross-browser testing (Chrome, Firefox, Edge, mobile Safari).

Accessibility check (aria labels, tab order).

Image optimization (serve WebP where helpful).

Minify CSS/JS for production.

Prepare .htaccess or route rules for pretty URLs (if using Apache).

Deployment:

Static-only pages can be tested on GitHub Pages/Netlify.

For PHP + MySQL, choose a host with PHP + MySQL (shared hosting, VPS, or a PaaS that supports PHP). Deploy via FTP/SFTP or Git depending on host.

Done when: Site runs on the chosen host, admin features work, and contact/event registration persists to DB.
